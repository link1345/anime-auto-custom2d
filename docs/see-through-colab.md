# See-throughをColabで実行する

## 準備

アプリを起動し、顔専用の正方形画像を登録する。FFmpeg拡大を有効にすると2160または3072へLanczosで拡大する。元から選択値より大きい画像は縮小しない。顔の構図を確認し、重ね合わせで原画の顔位置に配置する。添付のNagi顔は2160×2160。

「① Colabノートブック」と目的の「② ジョブ ZIP」をダウンロードする。顔と髪・体は別々に実行する。顔ジョブは拡大顔、体ジョブは原画を含む。ZIPにAPIキーは不要。

## Colab設定と実行

1. https://colab.research.google.com/ の「ノートブックをアップロード」で `Nagi_SeeThrough.ipynb` を開く。
2. 「ランタイムのタイプを変更」でGPUを選択。2160の処理にはL4 24GB以上またはA100を使う。ノートブックは22GB未満を検出すると止める。使用可否や処理時間・メモリ消費は未実測。
3. `USE_DRIVE = True` ならDriveを接続する。`MyDrive/NagiStudio-SeeThrough`にジョブ・ログ・結果を保存する。不要ならFalseへ変更できるがランタイム終了時に失われる。
4. `GROUP_OFFLOAD = True` のまま上から実行する。固定された公式コードと依存パッケージ、モデルを取得するため、初回はネット接続とダウンロード待ちが必要。
5. アップロード欄でアプリから出力したジョブZIPを1つ選ぶ。
6. 最後のセルから結果ZIPをダウンロードし、アプリの「③ See-through結果 ZIP」で開く。
7. 未検出の警告、顔の位置、レイヤーの重なりを確認して「採用」。元の仮パーツは必要に応じて非表示にする。保護済みパーツは保持される。

## 保存する分類

顔: 眉毛・まつげ・口・鼻・肌・耳・瞳・白目。髪などは顔結果に混ぜない。モデル内部の処理は公式の全レイヤー推論を使い、出力を8種類に絞る。

髪・体: 前髪・後ろ髪・首・上衣・手袋/手元・下衣・脚衣・靴。上衣に腕や袖がまとまる場合は切断ツールで細分化し、動く部位を割り当てる。原画にない脚などの取得は保証しない。

2160画像は白い余白を加えて2176で推論し、余白8pxずつを切り戻す。原画は縦横比を保って正方形に余白追加する。失敗時に解像度を下げる処理はない。

## 失敗・再開

- VRAM不足: A100など余裕のあるGPUへ変更して再実行する。CPUメモリ不足でも停止する場合がある。
- 同じジョブを再実行すると、同じ入力・設定・公式コミットでの推論完了マーカーがある場合に結果包装から再開する。途中で失敗した推論は先頭から実行する。
- ログ: `work/<job-id>/inference.log`、失敗状態: `failure.json`。失敗を成功した結果ZIPとして出力しない。
- 顔素材や原画を差し替えた場合は新しいジョブを出力する。古い入力に対する結果はアプリが拒否する。
- 候補生成後に編集した場合も再取り込みが必要。素材が同じならジョブの再推論は不要。
- 採用前の候補はディスクへ保存され、アプリ再起動後に「未採用の結果候補を再表示」で復元できる。同じリビジョンの候補だけを表示する。
